Google Sheets Setup

Follow these steps once and your product catalog will automatically pull from your Google Sheet every time someone visits the site. No coding needed after setup — just edit the sheet and the website updates itself.

  1. 1
    Create your Google Sheet

    Go to sheets.google.com and create a new spreadsheet. Name it anything you like, e.g. Custom Tags Plus — Products.

  2. 2
    Add these exact column headers in Row 1

    The header names must match exactly (capitalization doesn't matter). Add them starting from column A:

    ColumnRequired?What to put in it
    nameRequiredProduct name, e.g. Large Cattle Button Tag
    descriptionRequiredFull product description
    animalOptionalCattle, Sheep, Goats, Swine, Horses…
    styleOptionalButton, Flag, Two-Piece, Visual ID…
    sizeOptionalSmall, Medium, Large, Extra Large…
    colorOptionalYellow, Green, Red, Blue, Orange…
    priceOptional$1.25/tag — or leave blank for "Contact for pricing"
    badgeOptionalPopular, New, Sale — shows as a gold badge on the card
    image_urlOptionalDirect URL to a product photo (must be publicly accessible)

    Fill in rows 2, 3, 4… with each product. Add or edit rows anytime — the site always loads the latest data.

  3. 3
    Publish your sheet to the web

    In Google Sheets, click File → Share → Publish to web. In the dialog, select your sheet tab, choose Comma-separated values (.csv) format, then click Publish. Confirm when prompted.

  4. 4
    Copy the CSV link and paste it below

    After publishing, Google gives you a link that looks like:
    https://docs.google.com/spreadsheets/d/…/pub?gid=0&single=true&output=csv
    Copy that full URL and paste it into the box below, then click Save.

    ✓ URL saved! Switch to the Store tab to see your products.
  5. 5
    For slideshow photos (optional)

    Upload photos to any public host (Google Drive with link sharing on, Imgur, GitHub repo, etc.) and paste the direct image URL into the image_url column of your sheet. For the hero slideshow at the top of the page, open index.html in a text editor and replace the gradient backgrounds on .slide-1 through .slide-5 with background-image: url('your-photo.jpg').

The URL you enter is saved in your browser's local storage so you only need to do this once per device. When you push this file to GitHub Pages, paste the same URL directly into the SHEET_CSV_URL variable at the top of the <script> section in index.html so it works for all visitors without them needing to set it up.
