Google Sheets Setup

Follow these steps once and your product catalog and slideshow will automatically pull from your Google Sheet every time someone visits the site. Just edit the sheet — the website updates itself.

  1. 1
    Create your Google Sheet

    Go to sheets.google.com and create a new spreadsheet. Name it anything you like, e.g. Custom Tags Plus — Products.

  2. 2
    Add these exact column headers in Row 1

    Header names must match exactly (capitalization doesn't matter). Add them starting from column A:

    ColumnRequired?What to put in it
    nameRequiredProduct name, e.g. Large Cattle Button Tag
    descriptionRequiredFull product description
    animalOptionalCattle, Sheep, Goats, Swine, Horses…
    styleOptionalButton, Flag, Two-Piece, Visual ID…
    sizeOptionalSmall, Medium, Large, Extra Large…
    colorOptionalYellow, Green, Red, Blue, Orange…
    priceOptional$1.25/tag — leave blank for "Contact for pricing"
    badgeOptionalPopular, New, Sale — shows as a gold badge on the card
    inventoryOptionalA number (e.g. 42) or text: "In Stock", "Low Stock", "Out of Stock"
    image_urlOptionalDirect URL to a product photo (publicly accessible)
    slideshow_urlOptionalPhoto or .mp4 video URL to show in the hero slideshow
    slideshow_typeOptionalLeave blank for photos. Put video for .mp4 files
    slide_titleOptionalHeadline text for the slideshow (e.g. "Yellow Cattle Tags")
    slide_subtitleOptionalSmaller caption under the headline (e.g. "UV-stable, weatherproof")

    Fill rows 2, 3, 4… with each product. Add or edit rows anytime — the site always loads the latest data.

  3. 3
    Publish your sheet to the web

    In Google Sheets: File → Share → Publish to web. Select your sheet tab, choose Comma-separated values (.csv), then click Publish.

  4. 4
    Paste the CSV link below and save

    Google gives you a URL like:
    https://docs.google.com/spreadsheets/d/…/pub?gid=0&single=true&output=csv
    Paste it here and click Save & Load.

    ✓ URL saved! Switch to the Store tab to see your products.
  5. 5
    Slideshow images

    Add a public image URL in the slideshow_url column for any row you want featured in the hero slideshow. Use slide_title and slide_subtitle to control the text overlay. Rows without a slideshow_url won't appear as slides. If no rows have a slideshow URL the default gradient slides show instead.

  6. 6
    Inventory

    Put a number like 42 in the inventory column and the card shows a green "42 in stock" badge. Values ≤5 show yellow "Low stock". 0 or the text Out of Stock shows red. Leave blank to hide the inventory display entirely.

  7. 7
    Make it permanent for all visitors

    Open index.html in a text editor, find const SHEET_CSV_URL = ''; near the top of the script, and paste your URL between the quotes. This makes the sheet load for everyone without needing to use the Setup panel.

To access this Setup panel again: click the page footer 5 times quickly and log in.
